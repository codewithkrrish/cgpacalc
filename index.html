    Please read: honest limitations

    • Grade scales differ by university. The default 10-point scale (O=10 down to F=0) is common in India but not universal. Check your institution's scale and adjust the custom scale above if yours differs.
    • Percentage conversion is an estimate. The default factor of 9.5 is widely used, but many universities publish their own formula. CGPACalc labels the result "approximate" for exactly this reason.
    • Failed subjects: an F counts 0 grade points and its credits still count in the denominator (SGPA over attempted credits), which is the standard rule most universities follow. Some institutions exclude failed credits instead — if yours does, remove the failed row to model that rule.
    • Rounding: displayed values are rounded to two decimals; the underlying calculation keeps full precision.
    • Local only: nothing is sent to any server, so there is no account, no sync, and clearing browser storage removes your saved data. Export JSON for a backup.
